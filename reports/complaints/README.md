# 신고서 검토 초안

공식 법령과 객관적 증거를 교차 검증한 S등급 사례만 이 폴더에 Markdown 초안으로 등록합니다. 실제 신고는 저장소 소유자가 검토 후 직접 진행합니다.

- 파일명: YYYY-MM-DD-<candidate-id>.md
- 동일 근거의 중복 초안은 생성하지 않습니다.
- 기존 초안은 덮어쓰지 않고 근거 변경 시 별도 개정본을 생성합니다.
- 공개 저장소이므로 개인정보, 계정 정보, 비공개 증거, 인증정보를 포함하지 않습니다.
- 자동 생성 결과는 위법 확정 또는 기관의 판단이 아닙니다.
- 검토 상태: draft / owner_reviewed / withdrawn. 제출 여부는 소유자만 기록합니다.
