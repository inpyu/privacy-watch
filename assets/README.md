# Manual evidence assets

공식 문서를 직접 다운로드하여 유형별 폴더에 등록합니다.
- guidelines: 안내서 및 가이드라인
- interpretations: 법령 해석자료
- enforcement_cases: 행정처분 의결서
- precedents: 판례

manifest.json에 id, title, issuer, version, file, source_url, publication_date, binding, verification_status를 기록합니다. 공식 출처와 유효성 및 재배포 허용 여부를 확인하고 개인정보가 포함된 자료는 등록하지 않습니다. PDF는 매일 로컬에서 자동 탐색하고 페이지별 텍스트를 추출합니다. manifest 미등록 파일도 인식하되 공식 출처 검증은 별도입니다. press_materials 및 catalogs는 비교 대상에서 제외합니다. PDF 텍스트 추출은 이미지·표의 완전한 해석을 보장하지 않습니다. 기존 evidence/manual은 역사적 자료로 보존하되 수집 대상에서 제외합니다. 키워드 후보는 신고 근거가 아니며 ChatGPT의 법적 검증이 필요합니다.
