# Manual evidence assets

공식 문서를 직접 다운로드하여 유형별 폴더에 등록합니다.
- guidelines: 안내서 및 가이드라인
- interpretations: 법령 해석자료
- enforcement_cases: 행정처분 의결서
- precedents: 판례

manifest.json에 id, title, issuer, version, file, source_url, publication_date, binding, verification_status를 기록합니다. 공식 출처와 유효성 및 재배포 허용 여부를 확인하고 개인정보가 포함된 자료는 등록하지 않습니다. 현재 자동 분석 코드와는 연동되지 않습니다.
